一起数数

从「一个累加的数字」变成「一本日历账」。每一天都是一个格子，一天里想记多少条就记多少条，每条都记着几点几分、加了多少、谁记的。加错改错都行，合计永远自动算好；重要的日子钉上星标做成纪念日；设一个目标（也可以不设），它就按你最近的节奏预测哪天达成。

月历筛选 · 点哪天看哪天 一天多条 · 时刻细到分 提交后仍可改 · 自动求和 纪念日星标 · 常亮日历 可选目标 · 预测达成日 标签可命名 · 好友共同维护 导入导出 · 模板格式

本轮重构数据模型从「累加器 + 本地快照」升级为「标签 → 日 → 条目」三层的日历账本：默认 12:00 记一笔、时刻可改、数量可正可负、提交后逐条可编辑、合计现算不落死值；标签自定义命名随时改，口令分享后好友共同维护、每条署名、实时落库同步；新增 JSON / CSV 模板导入导出。本轮追加：可选目标 + 简单可解释的预测（不填不打扰，填了按近两周加权日均预测达成日）；界面做减法：统计并成单行、当日明细并入日历卡、条目改时间轴平铺——容器更少、密度不降。V5 / V6 设计稿原样保留，本稿为全新对照版。

纪念日星标

原「标记历史」升级：把选中的那天立为纪念日，日格右上 ★ 常亮；纪念日列表记录日期、名字与当天累计值，可改名可删。是里程碑，不是流水。

目标进度 · 预测

目标可选：不填整块不渲染，零打扰。填了就在大卡片挂一条蜜瓜进度条 +「预计 X月X日 达成 · 日均 Y」：算法取近两周加权日均（近 7 天 ×2、前 7 天 ×1），端上可算、一句话能讲清。预计达成日在月历上以蜜瓜虚线旗标预告，随每笔落账实时修正；达成当笔弹庆祝并引导立纪念日。

动效规则

落账弹跳

保存一笔后：大卡今日合计 0.18s 弹性放大回弹；对应日格合计数字同步弹一下。改账、删账同样触发重算动画。

选日切换

点日格：选中态 0.15s 填色，下方当日明细 0.22s 淡入上移；翻月整片刷新，位置记忆回月首。

星标与署名

立纪念日成功：★ 在日格右上 0.3s 弹出，列表同步多一行；好友落账时条目行带头像 0.25s 淡入。

删除两步确认

条目 / 纪念日 / 标签删除都先变红（confirm 态），再点一次才执行；浮层一律 0.3s 上滑 + 背景压暗，全部尊重系统「减弱动态」。

进度与达成

落账后进度条 0.4s 流畅补位，预测日期随之实时修正；跨越目标的一笔弹出「🎉 达成目标」并引导立纪念日；月历预计达成日以蜜瓜虚线预告。

02数据模型 V7（三层账本）

tag { id, name, unit, colorIdx, target?,
     owner, members[], shareCode,
     version, updatedAt }  // target 不填 = 不开启预测
entry { id, tagId,
       date 'YYYY-MM-DD', time 'HH:mm',
       amount // 可正可负，修正就记 −1
       note?, by, updatedAt }
anniversary { id, tagId, date, label,
            valueAtMark }  // 当天累计存档

event { id, tagId, type: 'entry.add|edit|del|tag.update|ann.*', payload, by, ts }
合计永远现算：日合计 / 月合计 / 累计都从条目求和，不落死值，改哪条补哪块。
条目级 last-write-wins：每条有独立 updatedAt，两人改同一天不同条互不冲突。
离线照记：本地先落 outbox（复用现有队列），联网按事件序补传。

04目标预测模型（端上可解释）

// 不加接口、不加表：target 存 tag 上，预测端上现算
rate = ( Σ近7天日和×2 + Σ前7天日和×1 ) / 21  // 加权日均，近况话语权更大
eta  = today + ceil((target − 累计) / rate)

// 边界
target 未填   → 模块整体不渲染，零打扰
rate = 0      → 「最近两周没有进展」，不出假日期
累计 ≥ target → 「已达成」+ 引导立纪念日（成就闭环）
预测随每笔落账实时修正；月历在预计日挂蜜瓜虚线旗标，翻月也能看到。
target 走既有 PATCH /tags/:id 同步，好友端共享同一目标与同一份预测。
算法可替换升级（线性回归 / 按星期加权），展示层与接口都不用动。
