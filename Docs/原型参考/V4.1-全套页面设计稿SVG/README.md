# V4.1 全套页面设计稿（SVG · Figma 可导入）

29 张 375×812 设计稿，对应 V4.1 修复+美化后的最终视觉。所有图层（`<g>`）带语义命名，导入 Figma 后图层面板直接可读、可单独调整。

## 导入 Figma

1. Figma 画布空白处右键 → **Place image / 放置图片**，或直接把 `.svg` 文件拖进 Figma。
2. 拖入后默认是矢量图层，双击可进入任意分组编辑（文字仍是 text，可改字体字号）。
3. 建议一次全选拖入，Figma 会自动按 375 宽对齐排列。

- `00-设计系统` — 色板 / 字阶 / 按钮组件（改版基准）
