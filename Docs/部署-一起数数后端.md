# 一起数数 v2 · 后端部署指南（counter.mariana66.xyz）

> 目标：把 `server/index.mjs` 部署到你的阿里云服务器，通过 `https://counter.mariana66.xyz` 提供服务。
> 全程零成本（Let's Encrypt 免费证书 + 已备案域名 + 已有服务器），预计 30 分钟。
> **不需要任何管理后台/可视化页面**——数据增删全部由小程序用户自己完成，服务器只是同步中枢。

## 0. 前置条件

- 阿里云 ECS（或同类），可 SSH 登录
- Node.js **≥ 22.5**（`node:sqlite` 需要；建议直接装 Node 24 LTS）
- 域名 mariana66.xyz 已备案（你已确认），解析控制台可加子域记录
- 个人网站已在根域名跑 Nginx（互不影响，子域是独立 server 块）

## 1. DNS：加一条子域记录

在域名解析控制台（阿里云云解析 DNS）添加：

```
记录类型: A
主机记录: counter
记录值:   你的服务器公网 IP
TTL:      600
```

等 2~10 分钟生效：`ping counter.mariana66.xyz` 返回服务器 IP 即可。

## 2. 上传代码

只需 1 个文件：`server/index.mjs`。在服务器上：

```bash
mkdir -p /opt/counter
# 本地上传（任选其一）：
scp server/index.mjs root@<服务器IP>:/opt/counter/index.mjs
# 或 git 拉取后复制：
cp FunToolsDirector/server/index.mjs /opt/counter/index.mjs
```

## 3. 安装 Node 24（如未装）

```bash
curl -fsSL https://deb.nodesource.com/setup_24.x | bash -
apt-get install -y nodejs
node -v   # v24.x
```

## 4. 先裸跑一次验证

```bash
cd /opt/counter
TRUST_PROXY=1 PORT=8787 HOST=127.0.0.1 node index.mjs
# 另开一个终端：
curl http://127.0.0.1:8787/api/v1/health
# 返回 {"ok":true,"data":{"service":"counter",...}} 即成功
```

数据文件会自动生成在 `/opt/counter/data/counter.db`（SQLite，WAL 模式）。

## 5. 用 systemd 常驻

`/etc/systemd/system/counter.service`：

```ini
[Unit]
Description=Counter (一起数数) backend
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/counter
ExecStart=/usr/bin/node index.mjs
Environment=PORT=8787
Environment=HOST=127.0.0.1
Environment=TRUST_PROXY=1
Restart=always
RestartSec=3
# 数据备份：直接拷 data/counter.db（WAL 模式请先停服或用 sqlite3 .backup）

[Install]
WantedBy=multi-user.target
```

```bash
systemctl daemon-reload
systemctl enable --now counter
systemctl status counter
```

## 6. Nginx 反代 + HTTPS

`/etc/nginx/sites-available/counter.mariana66.xyz.conf`：

```nginx
server {
    listen 80;
    server_name counter.mariana66.xyz;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name counter.mariana66.xyz;

    # 证书路径见第 7 步 certbot 自动填写
    ssl_certificate     /etc/letsencrypt/live/counter.mariana66.xyz/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/counter.mariana66.xyz/privkey.pem;

    client_max_body_size 4m;   # 照片接口上限 2MB，留余量

    location / {
        proxy_pass http://127.0.0.1:8787;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

```bash
ln -s /etc/nginx/sites-available/counter.mariana66.xyz.conf /etc/nginx/sites-enabled/
nginx -t
```

## 7. 免费证书（Let's Encrypt 自动续期）

```bash
apt-get install -y certbot python3-certbot-nginx
certbot --nginx -d counter.mariana66.xyz
# 按提示填写邮箱、同意条款即可；certbot 会自动改写上面的证书路径并配置续期
```

续期已由 certbot 的 systemd timer 自动处理，无需人工干预。

## 8. 最终验证

```bash
curl https://counter.mariana66.xyz/api/v1/health
```

返回 `{"ok":true,...}` 即上线完成。

## 9. 小程序后台配置（关键，别漏）

微信公众平台 → 开发管理 → 开发设置 → 服务器域名 → **request 合法域名** 添加：

```
https://counter.mariana66.xyz
```

`counterApi.ts` 里 `COUNTER_API_BASE` 已写成该地址，无需改代码。

## 10. 备份

数据全在 `/opt/counter/data/` 一个 SQLite 文件：

```bash
systemctl stop counter
cp /opt/counter/data/counter.db /backup/counter-$(date +%F).db
systemctl start counter
```

建议加一条 crontab 每周备份。

## 环境变量速查

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | 8787 | 监听端口 |
| `HOST` | 0.0.0.0 | Nginx 后面建议 127.0.0.1 |
| `DB_PATH` | `<目录>/data/counter.db` | SQLite 路径 |
| `TRUST_PROXY` | 0 | 反代后置 1，取真实 IP 做限流 |
| `TLS_KEY_FILE` / `TLS_CERT_FILE` | 空 | 不用填（TLS 由 Nginx 终结） |
