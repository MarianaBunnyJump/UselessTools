动效规则

数字弹跳

±1 时大块数字 0.18s 弹性放大到 1.1 回弹，只动数字不动整板；小块数字同步更新但不动画。

标记成功 tick

点击标记历史：按钮右上角弹出一个绿勾（0.5s），下方时间戳行 0.25s 淡入，历史徽章 +1。一个动作，三层确认。

删除两步确认

小块卡上的删除按钮先变红（confirm 态），再点一次才删除卡片；历史条目同理先红后删。

切换与抽屉

点小块切大块：数字区 0.2s 淡入新值；浮层一律 0.3s 上滑 + 背景压暗。全部尊重系统「减弱动态」。

落地到趣工局

单页结构更轻：一个页面 + 三个浮层。数据模型同步精简，历史时间戳先落本地，随账号体系再上云。

02数据模型（精简版）

// 无图标、无目标、无小计数点；新增 history 时间戳
card {
  id, title, colorIdx, unit,
  value,// 主计数
  history: [{ id, ts, value }], // 本地时间戳快照
  owner, members: [openid...],
  version, updatedAt// 乐观锁
}

event { cardId, userId, delta, ts } // 增量：计数与历史标记都走它
「标记历史」本地写入 { ts, value } 快照；与 +1 一样作为增量事件同步，好友也能看到你的标记。
离线可数可标记：本地先记，联网后按事件序补传；冲突按事件级 last-write-wins。
分享链接 = cardId 短链 + 4 位口令，新成员凭口令加入 members 共同计数。
