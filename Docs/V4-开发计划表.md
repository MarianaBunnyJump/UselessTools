## 一、软件说明（V4 完成后的最终效果）

**趣工局 = 一间装得下 20 个工具的口袋工局。**

**首页**：右上角一键切换两种模式——
- **礼盒模式**（现有）：礼物盒网格 + 全屏皮肤（圣诞树挂卡、星夜、玩具工局），拖动整理
- **简洁模式**（新）：分类分组列表（学习·校园 / 创作·图片 / 生活计算 / 趣味），每类一块北欧风几何装饰带（简版圣诞树、晨雾山形，纯背景不抢卡），右侧悬浮索引条点击跳组；右上「整理」进入编辑模式：点眼睛隐藏/放出卡片、长按拖动排序、改分类归属、新建分类、上传图片替换任意图标（仅本机）

**工具全景**（★=趣味差异化点）：

| 分类 | 工具 | 一句话 |
|------|------|--------|
| 学习 | 文言文陪读 | 小初高课本文言文，逐句拼音+点击朗读+★背诵挖空自查+局长批注 |
| 学习 | 汉字笔顺 | 笔顺演示+★跟写打分 |
| 学习 | 字帖生成器 | 姓名/课文→田字格描红帖可打印 |
| 学习 | 拼音注音 | 任意文本逐字标拼音，多音字可纠错 |

| 创作 | 拼豆图纸生成器 | 图片→48色拼豆图纸+★每色颗粒购物清单+内置模板 |
| 创作 | 手持弹幕 | 全屏滚动大字+★接机镜像模式+摇一摇换色 |
| 创作 | 文字转图片 | 便签/长图/九宫格三种版式 |
| 创作 | 图片小工具箱 | 裁剪调色贴纸+★EXIF隐私一键清理 |
| 生活 | 生活计算器合集 | 单位/健康/房贷/复利/个税/日期/油耗/旅行AA+金额大写，★每个结果配「局长碎碎念」人话解读 |
| 趣味 | 假装来电 | ★剧本式模拟来电（TTS念台词）帮你体面撤退 |

**底线**：无广告无登录不变、全部本地运行、朗读走微信官方免费同声传译插件（失败自动降级）、主包 <900KB 其余分包按需加载、每工具文案语料集中在 data 目录随时可改。
