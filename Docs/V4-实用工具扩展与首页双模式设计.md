# V4 · 实用工具扩展与首页双模式设计（评审稿）

> 项目：趣工局（微信小程序 · 个人主体 · 纯本地无后端）
> 文档版本：v1.0（**评审稿：本稿只做规划与设计，不含任何代码改动**）
> 日期：2026-09-25
> 策略背景：现工具偏解压/谈资，留存薄。本轮起补充**实用型工具**获取新用户与回访（实用场景搜索 + 高频刚需），同时坚持「人无我有、人有我优」——**每个工具必须带一个别人没有的趣味化设计**，趣味是我们区别于同类工具箱的护城河。

## 0. 总原则（先立规矩）

1. **纯本地零后端不变**：所有工具必须能在本地完成；需要数据的大件（文言文语料、拼音字典、笔顺库）走**分包**，按需加载
2. **趣味化是硬性验收项**：每个工具有一条「人无我有 / 人有我优」的差异化设计，写进验收清单；纯复刻市面产品的不立项
3. **与现有工具整合优先于重复造**：抽签/点名/今天吃什么/喝酒转盘全部并入现有**转盘选择器**的「场景预设包」，不新建重复工具——这是「人有我优」的第一步
4. **三无良心不变**：无广告、无登录（用户页保留访客态）、无功能墙；图片上传仅存本机
5. **主包红线**：新增工具全部走分包，主包保持 < 900KB（当前 675KB）

## 2. 第一批工具详细设计（★ 五个，待逐个审核）

### T1 · 文言文陪读 📖（本批旗舰，人无我有）

**页面结构（分包 study，语料按「学段/册」二级分包）**

- **书架页**：学段 Tab（小学 / 初中 / 高中）→ 册列表（部编版目录，如「七年级上」）→ 课文行（篇名 / 作者 / 已读标记 ✦）
- **课文页**（SVG 已出）：
  - 标题 + 朝代作者；正文**逐句分段**，每句下挂拼音行（小号、灰），点击任意句：
    - 单句高亮 + 自动朗读（微信同声传译插件 `WechatSI`，首用弹插件授权）
    - 朗读中句子加重点号；支持「本篇连播 / 单句循环 / 语速 0.8×/1×/1.2×」
  - 实词注释：句内深色小点标记，点击弹出**白话释义浮层**
  - 顶部工具行：背诵模式 / 字号 / 连播开关
- **背诵挖空模式（人无我有）**：进入后全文变成「填空卡」——每句随机遮住 30% 的字（点击显示），长按整句遮全句；页底「我都背下来了」自评 → 记入本篇进度（⭐→⭐⭐→⭐⭐⭐ 背熟）
- **进度**：读过 ✦ / 背熟 ⭐⭐⭐ 标记存本机；书架页顶部显示「已读 n / 全部 m」
- **趣味化细节**：每篇末尾一条「局长批注」——一句现代视角的碎碎念（如《陋室铭》：「房子小不要紧，网友多才是真的」），可配置语料；这是传播点
- **数据与成本**：语料 = JSON（句 + 拼音 + 注释 + 批注），单篇 8~15KB；小初高约 60 篇 ≈ 700KB → 全部进**语料分包**，按学段再拆 3 个子分包；拼音内置在语料中（人工校对，不依赖运行时字典）；插件：微信同声传译（免费、官方，需在 app.json 声明 + 首次授权）
- **风险**：插件授权失败 → 全文可看拼音可读，仅朗读降级提示；课文篇目以「部编版常见篇目」为准，标注「收录为常见课本篇目，具体以你所学教材为准」

### T6 · 拼豆图纸生成器 🧩

**流程**：选图（相册）→ 参数（板型 15cm/29×29 与小方珠色数、色数上限 24/48、是否描边）→ 生成 → 图纸页

- 取色：图片缩到目标格数 → 逐格在 48 色拼豆色板中找最近色（LAB 色差），色数超上限自动合并相近色
- **图纸页**（SVG 已出）：像素网格预览（可捏合缩放）+ **颗粒清单**（每色色号 + 颗数 + 小色块，可勾选「已有」）+ 换算条（15cm 板 ≈ 29×29；总颗粒数）
- 导出：带网格线 + 色号的图纸大图（存相册/打印）；趣味：**「趣工局模板库」**——内置礼盒、木鱼、圣诞树、 fortune 猫 4 个像素模板直接生成图纸
- 差异化：市面像素化工具输出的是「马赛克图」，我们输出的是**能直接照着买的购物清单 + 图纸**

### T7 · 手持弹幕 📱

- 首页：大输入框 + 预设文案 chips（「接 ~ 机 ~」「求带走」「前方高能」）→ 全屏播放页
- 播放页（SVG 已出）：文字横向滚动，速度/字号/方向/前景背景色可调；**镜像应援模式**：上下两半镜像滚动（接机时举过头顶对面也能读正字）；摇一摇随机换配色对；播放中点按暂停
- 趣味：文案历史本地保存 8 条；「荧光排版」固定 3 套配色对（黑底荧光绿 / 白底玫红 / 深蓝底暖黄）

### T12 · 假装来电 ☎️

- 配置页：来电人（通讯录文案自定义，如「妈妈」/「王老板」）+ 头像 emoji + 延迟秒数（10s/30s/1min/3min）+ 台词（接通后朗读，TTS 同 T1 插件）
- 来电页（SVG 已出）：全屏仿来电界面（头像 + 滑动接听/挂断）+ 渐强铃声（合成，不侵权）+ 真机震动节奏；接听后进入「通话中」页朗读台词（或静音只是撑场面）
- 趣味：**剧本预设**——「妈妈喊回家吃饭」「老板临时召唤」「快递到了」三套内置台词，一键套用；挂断后一句小结「成功撤退 · 本周第 2 次」（本地计数，纯自嘲无排行）
- 合规注意：界面明确标注「模拟来电演练」，避免被认定为诈骗工具；不读取真实通讯录

### T2 · 汉字笔顺 ✍️

- 搜索/输入一个汉字 → hanzi-writer 动画演示笔顺 → **跟写模式**：手指在格内书写，逐笔判对错（hanzi-writer quiz 能力），错笔抖动提示
- 数据：char 数据按字加载（每字 ~2-8KB），常用 3500 字打包进分包（约 12MB 超限 → 改为**按字分包拉取**：只内置动画引擎，字数据按需从分包内的子包集取，首版收录课标 700 字）——**此项成本最高，放第一批末位，可延后**
- 趣味：连续跟对 10 字解锁「笔顺之神」本地称号（与成就体系联动）

## 3. 首页双模式（H1，配合工具扩容的骨架改版）

### 3.1 两种模式

| | 礼盒模式（现有） | **简洁模式（新）** |
|---|---|---|
| 形态 | GiftBox 网格 + 皮肤景深 | **分类分组列表**：分类头 + 2 列「图标 + 名称 + 一句话」卡 |
| 背景 | 全屏皮肤（圣诞树可与卡交互） | **纯背景**；皮肤元素只出现在**分区装饰块** |
| 适合 | 少工具、品牌感、趣味 | **工具多之后的检索效率**（本轮扩容的主模式） |
| 切换 | 首页右上角胶囊按钮 + 设置页持久化（`home_layout_mode`） | 同左，一键切换 |

### 3.2 简洁模式规格（比参考图更规范的点）

- **分组头**：左侧分类小图标 + 分类名（如「学习 · 校园」），右侧该组数量徽标；分组头吸顶（scroll-view 锚点导航：右侧悬浮分类索引条，点击跳组）
- **卡片**：2 列，白底 12% 透明度、圆角 24、左侧 88px 圆角图标位 + 名称（28）+ 一句话描述（22，超两行省略）；**无分组内边框线**，靠间距分组（参考图用灰底分组块 + 描边，我们更轻）
- **装饰块（分区背景）**：每个分类组的背景是一块独立的「景观带」——简洁版皮肤在此生效：北欧简版圣诞树 = 极简几何三角 + 雪点 + 单色晨雾山形，**纯装饰、不与卡片交互**（对比现有礼盒树皮的挂卡交互）；装饰块透明度 ≤ 12%，不抢卡片
- **北欧简洁版皮肤包**：现有 4 皮肤各出一套「简版」：同一色系、几何化元素、无雪花粒子循环（省性能）；礼盒模式沿用现有完整版

### 3.3 编辑模式（快捷自定义）

- 入口：简洁模式右上角「整理」按钮 → 进入编辑态（卡片轻微抖动，右上角出现可见性眼睛 + 分类归属标签）
- 能力：**隐藏/放出卡片**（隐藏后进「已收起」分组，随时可找回）、拖动排序、改分类归属（下拉选分类）、新建/重命名/删除分类（删除时工具自动回流「常用」组）
- 持久化：`home_categories`（分类定义与归属）、`home_hidden_tools`、`home_tool_order`（复用现有排序键）

### 3.4 图标系统

- 每个工具图标三层兜底：**用户上传 > 配置表指定 > emoji 默认**
- 配置表：`data/toolIcons.ts`——你上传的图标文件放 `assets/icons/`，表里登记路径即可全量生效（你来出一版统一图标）
- 用户自定义：长按卡片（礼盒模式）或编辑模式点图标（简洁模式）→ 上传正方形图（`chooseMedia` → 压缩 256px → 存 `USER_DATA_PATH/icons/<toolId>.png` → `tool_icon_overrides`）；随时一键恢复默认
- 合规：仅本机展示，无上传行为，隐私声明无需变更
