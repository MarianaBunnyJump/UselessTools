有点意思工具盒 — 交互微动效设计

Interaction & Micro-Animation Design v1.0 | 核心理念：工具盒不仅是名字，是贯穿全局的交互隐喻

本文档定义所有统一交互微动效。设计原则：每个动画都要有"打开盒子/拿出工具/放回盒子"的隐喻感，让"工具盒"概念可感知。动画服务于体验，不是炫技——每次动效时长控制在 150-600ms，不阻塞用户操作。

1. 工具盒核心隐喻动画

这是整个产品最关键的统一交互。用户每次进入工具和退出工具，都伴随"开盒/关盒"动画，强化"工具盒"品牌认知。

1.1 打开工具 — "开盒弹出"动画 全局统一

用户在首页点击任意工具卡片时触发。分 3 个阶段，总时长 500ms：

阶段时长动画描述实现方式
① 盒盖掀起0-150ms被点击的卡片顶部边缘向上翻转 15°（如盒盖掀起一条缝），伴随轻微阴影加深，暗示盒子内部CSS transform: perspective(600px) rotateX(-15deg) + box-shadow 加深
② 工具弹出150-350ms卡片内容（图标+文字）从盒子里"弹"出来，向上 scale(1.1) + translateY(-8px) + 弹性回弹，同时盒盖完全打开（rotateX 0°）transform: scale(1.1)→1.0 + translateY(-8px)→0, cubic-bezier(.34,1.56,.64,1)
③ 页面切入350-500ms整个工具页面从卡片位置展开铺满屏幕，背景毛玻璃渐变淡入。卡片本身淡出页面 opacity 0→1 + scale(0.95)→1, 背景渐变 opacity 0→1
// 卡片点击交互链 click card ├─ t=0ms: 卡片盒盖掀起 (rotateX -15deg, shadow+) ├─ t=150ms: 图标弹出 (scale 1.1, translateY -8px, 弹性回弹) ├─ t=350ms: 页面展开 (opacity 0→1, scale 0.95→1, 背景渐变淡入) └─ t=500ms: 卡片淡出，页面就绪 // 音效: "咔哒" 开盒声 + "啵" 弹出声（可选，用户可在设置中关闭）

1.2 返回首页 — "关盒收回"动画 全局统一

用户点击返回按钮时触发，是开盒动画的逆过程，总时长 400ms：

阶段时长动画描述
① 页面收缩0-200ms工具页面内容向中心收缩 scale(1)→0.92 + opacity 1→0，背景渐变淡出
② 盒盖合上200-400ms首页卡片从透明恢复显示，伴随盒盖合上的轻微"咔"效果（卡片 scale 0.96→1 弹性回弹）
// 返回交互链 click back ├─ t=0ms: 页面内容收缩 (scale 1→0.92, opacity 1→0) ├─ t=200ms: 首页恢复, 卡片盒盖合上 (scale 0.96→1, 弹性) └─ t=400ms: 首页完全就绪 // 音效: "咔" 关盒声（轻柔）

1.3 卡片闲置呼吸 全局统一

首页工具卡片在闲置状态有极轻微的呼吸浮动，让页面"活着"：

属性值
动画translateY(0 → -2px → 0) 无限循环
时长3-4 秒/周期，每张卡片随机延迟 0-2s（不同步）

幅度仅 2px，极其微妙，不干扰
触发页面可见 + 卡片未被按压 + 3秒无操作后开始

1.4 卡片按压 — "按进盒子" 全局统一

属性值

1.5 长按卡片 — "工具探头" 全局统一

长按卡片 500ms 后，卡片图标轻微"探头"（向上 peek），弹出简介弹窗：

阶段动画

4. 背景氛围动效

4.1 浮动粒子 背景层

每个页面背景有 5-8 个缓慢浮动的小粒子（小圆点、星星、小爪印），增强氛围感：

属性值
粒子形状小圆点(4px) / 小星星(✦) / 猫爪印(微缩SVG)，随机混合
颜色马卡龙色系随机，透明度 15-30%
运动缓慢上浮 + 轻微左右摆动，无限循环
速度每个粒子 15-25 秒完成一个循环，随机不同步
数量5-8 个，不影响性能
触发页面可见时持续运行

4.2 页面切换粒子爆发 背景层

开盒动画第②阶段（工具弹出）时，从卡片位置喷射 6-8 个马卡龙色小粒子，向外扩散并淡出：

属性值
起点卡片中心
方向360° 随机方向
距离30-60px 随机
时长500ms, ease-out 减速
淡出最后 200ms opacity 1→0

4.3 滚动视差 背景层

页面内容滚动时，背景渐变层以 0.3 倍速度缓慢移动，制造轻微视差感。粒子层以 0.5 倍速度移动。

8. 动效实现优先级

动效虽好，但不能全部一次做完阻塞开发。按优先级分批实现：

优先级动效理由
P0 必须有开盒/关盒动画、卡片按压、页面过渡、按钮交互核心品牌体验，没有就不叫"工具盒"
P0 必须有各工具核心功能动画（粉碎、转盘旋转、功德点击）工具本身的功能性动画
P1 应该有数字滚动、弹窗动画、Toast、列表项增删、成就解锁体验提升明显，开发量适中
P1 应该有统一音效（开盒/关盒/按钮）配合动画增强品牌感
P2 锦上添花浮动粒子、滚动视差、卡片呼吸、下拉刷新氛围动效，性能允许时加
P2 锦上添花所有专属微交互的细节打磨最后打磨阶段补
实现策略：第一版先做 P0 动效 + 功能，跑通全流程。P1 在联调阶段逐步加入。P2 在上线后根据用户反馈和性能情况补充。这样不会让动效开发拖慢核心功能进度。

9. 性能约束

指标要求
动画帧率≥ 30fps（Canvas 动画 ≥ 30fps，CSS 动画 ≥ 60fps）
单次动画时长≤ 600ms（除功能性动画如粉碎/转盘）
同时运行动画数≤ 8 个（粒子 + 呼吸 + 功能动画总计）
粒子数量单页 ≤ 8 个浮动粒子
音效实例池音效 InnerAudioContext 预创建复用，最多 5 个并发
动画属性优先 transform 和 opacity（GPU 加速），避免 layout 属性
will-change仅在动画期间设置，结束移除
低端机降级检测设备性能，低端机关闭粒子/视差，保留核心动画

10. 总结

本交互文档的核心设计理念是："工具盒"不是一个静态的名字，而是一套贯穿全局的动态交互语言。

每次进入工具 = 开盒取出工具。每次返回 = 放回工具关上盒子。每次分享 = 打开盒子给别人看。这个隐喻在 50+ 个微交互中被反复强化，让用户形成"打开我的工具盒"的心智模型，而非"使用一个小程序"。

统一动画 + 专属动效 + 背景氛围 + 音效配合 = 一个有生命力的工具盒。优先保证 P0 核心动效到位，P1/P2 逐步打磨。
